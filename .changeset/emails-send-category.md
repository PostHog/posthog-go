`CodeEmail` takes a `Category`, so code can send marketing email and file email under a message category. Set it to `posthog.MessageCategory{Key: "newsletter", Type: posthog.MessageCategoryMarketing, Name: "Newsletter"}`, which defines the category in code: the first send with a `Key` creates the category with its `Name` and `Description`. Later sends keep its name and description, so change them in PostHog. Leave `Category` out for transactional email with no category, as before, or for the category of the template that `TemplateKey` names. `posthog.EmailCategoryTransactional` asks for transactional email with no category, so PostHog refuses it with `category_mismatch` on a template in a category. A marketing send honors the recipient's opt-outs, and its body needs the `{{ unsubscribe_url }}` placeholder. PostHog refuses such a send with the error code `category_mismatch`, `too_many_categories`, `unsubscribe_link_required` or `recipient_opted_out`, and a `TemplateEmail` of a template in a marketing category with `unsubscribe_link_required` or `copies_not_allowed`.
